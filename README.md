# Bank-Management-System
Java-based Bank Management System using Java Swing, JDBC, and MySQL, supporting account creation, deposits, withdrawals, balance enquiry, mini statements, and PIN changes.
Bank Management System – ATM Simulator

# Project Overview

The Bank Management System is a Java-based ATM Simulator application designed to perform basic banking operations. It provides a user-friendly interface for managing bank accounts and simulating ATM transactions.

The application uses Java Swing for the graphical user interface and JDBC with MySQL for database connectivity and data management.

# Features

- Bank Account Creation
- Cash Deposit
- Cash Withdrawal
- Balance Enquiry
- Mini Statement
- ATM PIN Change
- Database Management
- User-friendly Graphical Interface

# Technologies Used

- Programming Language: Java
- Frontend: Java Swing
- Database: MySQL
- Database Connectivity: JDBC
- Concepts: Object-Oriented Programming (OOP)

# Project Modules

1. Account Registration
2. User Authentication
3. Deposit Management
4. Withdrawal Management
5. Balance Enquiry
6. Mini Statement
7. PIN Management

# Database

MySQL is used to store and manage customer account details and transaction records.

# How to Run

1. Install Java JDK.
2. Install and configure MySQL.
3. Create the required database and tables.
4. Configure the database connection in the Java application.
5. Add the MySQL JDBC driver.
6. Open the project in Eclipse IDE.
7. Run the main Java application.
